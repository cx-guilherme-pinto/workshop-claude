# Card pv-09 — Personal data in the URL

- **Category:** privacy
- **Difficulty:** 2
- **Template:** `spotTheFlaw` from `../../templates/spot-the-flaw.js`

## Concept

Personal data in a URL ends up in the history and in the logs of every server the request passes through.

## Prompt (field `prompt`)

This link was generated by a shop after you signed up. Which parts should not be in the URL?

## Content

Field `language`: `"url"`

Field `segments` (indexes start at 0):

```json
[
  "https://shop.example/welcome",
  "?source=newsletter",
  "&email=ana@example.com",
  "&phone=2025550143",
  "&lang=en"
]
```

Field `answer` (unsafe indexes): `[2,3]`

## Explanation (field `explanation`)

The URL is saved in the history, in server and proxy logs and in analytics tools. Send personal data in the body of a POST request, over HTTPS.
