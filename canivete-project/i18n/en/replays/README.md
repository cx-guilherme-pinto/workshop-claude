# `/status` replays

A replay rebuilds a run of the swarm on `/status` without calling the API: useful to rehearse, to show it on a projector with no network or to compare runs. The format is the same as the Security Arena's.

```
node server.js
http://localhost:3000/status?replay=example
```

(If port 3000 is busy, the server uses the next one and shows the right address.)

Each replay is a folder `replays/<name>/` (a name with lower-case letters, digits and hyphens) with two files.

| File | What it is |
|---|---|
| `events.jsonl` | The events of the run, one JSON per line, in the order they happened. It is the `.workshop/events.jsonl` that the orchestrator and the hooks write. |
| `snapshot.json` | The final snapshot (the same one `/api/status` returns). It gives the list and the order of the tasks, the titles, the result of each test and the real total cost. |

`example/` is **synthetic**: the 30 tools with 8 in parallel on Haiku, the 3 broken on purpose (`tx-02`, `nm-03` and `dn-01`) failing for good, then the search, the integration and the review. Its `snapshot.json` has `"synthetic": true`. It is generated by `tools/dev/make-canivete-replay.mjs`, in the kit's repository.

## Events (`events.jsonl`)

| `type` | Fields | Who writes it |
|---|---|---|
| `start` | `ts`, `mode`, `total` | `next-wave.mjs`, on the first batch |
| `state` | `ts`, `task`, `state` (`working`, `green`, `red`, `failed`), `attempt`, `agent`, `model` | `next-wave.mjs` (on launch) and `grade.mjs` (on grading) |
| `cost` | `ts`, `task`, `attempt`, `agent`, `model`, `cost_usd`, `duration_s` | the `SubagentStop` hook |
| `end` | `ts` | `next-wave.mjs`, when there is nothing left to do |

Lines that are not valid JSON are ignored. A `cost` event with `task: null` counts as the cost of the main session. On the `end` event, if the summed cost is lower than `snapshot.cost.total`, the difference goes to the main session, so the final number is the real one.

## Recording a real run

At the end of a `/demo-swarm`, with the server running:

```
mkdir -p replays/<name>
cp .workshop/events.jsonl replays/<name>/events.jsonl
curl -s http://localhost:3000/api/status > replays/<name>/snapshot.json
```

(If the server showed another port, use it in the `curl`.) Open `/status?replay=<name>` to check.
